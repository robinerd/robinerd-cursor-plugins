# Investigate repo

1. Skim structure, existing plans, tests, critical configs (read-only).
2. Propose tier: trivial | feature | breaking | spike — with one-line why.
3. List unknowns that block §1 or §4.
4. Do not implement. Suggest `/start-work` or `/define-feature` next.
